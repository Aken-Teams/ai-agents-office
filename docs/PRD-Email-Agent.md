## 1. 這是什麼

信件助手是一位 **AI 信件秘書**。打開它，就能在幾秒內快速看懂你的收件匣：

- 幫每封信寫一句話摘要，並標出**重要程度**（高／中／低）。
- 幫你**判斷可疑信件**（釣魚、詐騙、可疑附件）。
- 需要時，再針對某一封信做**深入分析**，給你行動建議與該怎麼回覆的方向。

目的是讓你「**打開就掌握今天的信**」，把時間花在真正重要的信件上。

---

## 2. 主要功能與觸發方式

| 功能 | 說明 | 怎麼觸發 |
|------|------|----------|
| **今日重點總覽** | 用一句話幫你摘要整個收件匣的狀況 | 🔵 打開時自動 |
| **每封一行摘要 + 重要程度** | 每封信一句話摘要、標示高／中／低、加上分類標籤 | 🔵 打開時自動（只對新信） |
| **單封深度分析** | 針對一封信給你：重點摘要、行動建議、資安判斷、建議回覆方向 | 🟠 你主動點「AI 深度分析」 |
| **附件深入分析** | 連同附件內容（PDF／Word／Excel／圖片）一起讀懂再判斷 | 🟠 你主動點「深入分析附件」 |
| **可疑信件判斷** | 標出釣魚、詐騙、可疑附件等資安風險 | 🟠 隨深度分析一起提供 |
| **聊聊這封信** | 針對這封信直接問 AI 問題 | 🟠 你主動開啟 |

> 🔵 = 自動（打開就有）　🟠 = 手動（你點了才會執行）
>
> 深度分析面板**預設是收合的**，避免你還沒需要時就自動執行；需要時點開即可。

## 3. Token（用量）說明

這部分最常被問到——**什麼情況會用到額度、什麼情況不會**：

| 動作 | 會不會用額度 | 說明 |
|------|-------------|------|
| 打開信箱、看每封一行摘要 | **幾乎不會** | 只有「**第一次出現的新信**」會做一次摘要；**看過的信會記住結果，再打開不會重複計算** |
| 滑動、瀏覽、看今日重點 | **不會** | 純瀏覽不花額度 |
| 點「AI 深度分析」 | 會（少量） | 你主動點才執行 |
| 點「深入分析附件」 | 會（較多） | 需要讀整份附件內容，是最花額度的動作 |
| 聊聊這封信 | 會（少量） | 你主動問才執行 |

**重點觀念：**

- 「**單純打開、看看摘要**」的花費很低，而且同一封信不會被重複計算。
- 主要用量來自你**主動做的深度分析**——尤其是**含附件**的信件（因為要把整份附件讀懂）。
- 小建議：需要深入了解、或有附件要判斷時，再點深度分析即可；一般瀏覽看摘要就很夠用。

---

## 4. 安全與隱私

- 信件助手**只會「讀」你的信**，不會替你回信、刪信、移動或改動你的信箱。
- 會主動幫你**留意釣魚、詐騙、可疑附件**，提醒你小心。
- 信件內容**只用於「幫你摘要與判斷」**，不做其他用途；系統在設計上會把信件內容當成需要謹慎處理的外部資料，**不會被信件裡的文字誘導而做出錯誤判斷**。

---

## 5. 目前可以做 / 還不能做

| 現在可以 | 目前還不行 |
|----------|-----------|
| 看每封摘要與重要程度 | 直接在助手裡回信 |
| 判斷資安風險（釣魚／詐騙） | 幫你把信歸檔、標記已讀、移動 |
| 深入分析單封信與附件 | 一鍵跳回原信處理 |
| 針對信件問 AI 問題 | — |

> 目前系統對信箱**僅開放「讀取」權限**，因此助手著重在「**幫你看懂、幫你判斷**」。若後續開放更多權限，便能再延伸「回信、歸檔、通報」等處理動作。
