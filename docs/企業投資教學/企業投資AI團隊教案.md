## 開課前一定要懂的產品事實

> **「AI 團隊」= 多角色分析 → 產出一份 Markdown 報告（可含圖表），會寄 Email、也能排程自動推播到 LINE。**
> 團隊成員本身只會「推理 + 上網查資料」，**不會直接產生 .pptx / .docx / .xlsx 檔**。
> 要真正輸出簡報／Word／Excel，得把團隊報告拿到**一般對話**，交給 `pptx-gen` / `docx-gen` / `xlsx-gen` 技能。

### 黃金動線（每堂課都在練這條）

```
①整理資料成 MD → ②餵給 AI 團隊分析（或排程自動跑）→ ③把報告丟到對話產出簡報 / Word / Excel
```

### 規格底線（程式裡寫死的，務必提醒學員）

| 項目 | 規格 | 教學提醒 |
|------|------|---------|
| 可上傳檔案 | `.md` `.csv` `.xlsx` `.pdf` `.docx` | 教學主推 **.md**，AI 最好讀 |
| 單檔大小 | 上限 50MB | 通常用不到 |
| 餵給團隊的字數 | **每檔約 12,000 字** | 資料要濃縮成重點，別塞長文 |
| 上傳檔案後 | **預設關閉上網**（純檔案模式） | 只用你的數字、查不到標「資料未提供」、不亂編 |
| 要補產業背景 | 手動按提問框 🌐 地球鈕開啟上網 | 網路數字會跟檔案數字分開標示 |
| 排程 | 只有「每天 / 每週」+ 時:分 + 收件 Email | 到點自動跑、寄信、推 LINE |
| 團隊記憶 | 會記得先前協作結論 | 可做「比較式追蹤」 |

## Lesson 1｜每天早上自動送到信箱的「盤前投資簡報」

> **入門班・約 90 分鐘**
> 不用學任何技術，先讓學員體驗「養一個會自己上班的投資團隊」。
> 核心技能：**排程設定** + **怎麼寫一句好的分析議題**。

### 學習目標

- 用內建範本 30 秒組出一支投資分析團隊
- 學會把「角度、清單、要的結論」講清楚的議題寫法
- 設好每日排程，讓報告自動進信箱 / LINE

### 時間分配（建議）

| 時間 | 內容 |
|------|------|
| 0–15 分 | 開場 + 合規免責 + 介紹「AI 團隊 = 自動研究助理」 |
| 15–35 分 | Step 1 建團隊（範本 + AI 微調） |
| 35–60 分 | Step 2 現場手動問一次，逐句拆解議題怎麼寫 |
| 60–80 分 | Step 3 設排程，每人設定自己的盤前簡報 |
| 80–90 分 | Q&A + 預告 Lesson 2 |

### Step 1 — 建團隊

團隊頁 → 選「**投資分析**」範本（系統內建 4 個角色），按需要用 AI 微調成學員自己的市場（台股 / 美股）：

| 角色 | 職責 |
|------|------|
| 國際局勢分析師 | FED 利率、通膨、地緣政治、美元黃金對市場的影響 |
| 市場關鍵因子分析師 | 產業趨勢、外資籌碼、政策供需的關鍵因子 |
| 多因子量化分析師 | 整合技術 / 籌碼 / 基本面的訊號強弱 |
| 風險監控師 | 黑天鵝、回檔、曝險集中度，永遠提醒下行風險 |

### Step 2 — 先手動問一次

在團隊提問框貼上以下議題（🌐 地球鈕**保持開啟**讓它上網查最新資料）：

```
請以「明天台股開盤前」的角度，幫我做一份盤前簡報：
1. 昨晚美股四大指數、費半、台積電 ADR 的收盤與隔日影響
2. 今天最關鍵的 3 個盤面因子（外資、權值股、產業消息）
3. 我的觀察清單：2330 台積電、2454 聯發科、2317 鴻海，各自今天要留意什麼
4. 風險監控師請給「今天最該小心的 1 件事」
請附資料來源網址，查不到的標註（推論）。
```

#### 👨‍🏫 教學重點：好議題的四要素

| 要素 | 這題裡的對應 | 反例（不要這樣寫） |
|------|------------|------------------|
| **角度** | 「明天開盤前」 | 「分析台股」 |
| **清單** | 列出 3 檔觀察股 | 「看看有什麼好股」 |
| **要的結論** | 「最該小心的 1 件事」 | 不講要什麼 |
| **資料紀律** | 「附來源、查不到標推論」 | 放任 AI 自由發揮 |

### Step 3 — 設排程

團隊頁 → 排程 → 新增：

| 欄位 | 填什麼 |
|------|--------|
| 排程名稱 | `每日盤前簡報` |
| 分析議題 | 把 Step 2 那段貼進去 |
| 頻率 | **每天** |
| 時間 | **08:00** |
| 收件 Email | 學員自己的信箱（綁 LINE 還會收推播） |

> 到點後團隊會自動跑、把報告寄到信箱。隔天 8 點驗收成果。

### 驗收標準

- [ ] 學員成功建立一支投資分析團隊
- [ ] 手動跑出一份含資料來源的盤前報告
- [ ] 設定好每日 08:00 排程，收件 Email 正確

### 課後作業

把議題改成自己真正關心的市場與持股，調整排程時間，連續收三天的盤前簡報，下堂課帶來討論「哪一份最有用、為什麼」。

## Lesson 2｜把自己的持股整理成 MD，做一次「個股健診」

> **進階班・約 120 分鐘**
> 全課最重要的一招：**把雜亂資料整理成乾淨 MD、上傳、用「純檔案模式」讓 AI 只根據你的真實數字分析。**
> 這堂示範了「AI 不會亂編，缺資料就說缺」——建立對工具的信任。

### 學習目標

- 學會把投資資料整理成 AI 最好讀的 MD 格式
- 理解「純檔案模式」：上傳檔案後預設不上網、不編造數字
- 把團隊的分析報告轉成一份 Word 健診書

### 時間分配（建議）

| 時間 | 內容 |
|------|------|
| 0–10 分 | 開場 + 回顧 Lesson 1 + 合規免責 |
| 10–40 分 | Step 1 帶學員一起填持股 MD |
| 40–70 分 | Step 2 上傳 + 純檔案模式提問，觀察 AI 回答 |
| 70–95 分 | 解讀報告、討論「資料未提供」代表什麼 |
| 95–115 分 | Step 3 把報告轉成 Word 健診書 |
| 115–120 分 | Q&A + 預告 Lesson 3 |

### Step 1 — 做一份持股 MD

發放本教案最後的「[持股範本](#範本-1my-holdingsmd)」，請學員填**自己的真實數字**。

#### 👨‍🏫 教學重點：MD 怎麼寫 AI 最好讀

- 用**表格 + 小標題**，數字一格一格清清楚楚
- 數字一定要**真實**（這堂的精神就是「基於真實數據」）
- 控制在**兩三千字內**（記得每檔只餵約 12,000 字）
- 把「我在意的問題」寫成清單，AI 才會逐題回答

### Step 2 — 上傳 + 純檔案模式提問

把 `my-holdings.md` 拖進團隊提問框（看到「放開以上傳檔案」就放開），🌐 地球鈕**保持關閉**（純檔案模式），貼上：

```
附件是我的真實持股。請團隊根據「檔案裡的數字」幫我健診，不要用檔案以外的數字：
1. 配置診斷：產業/個股集中度、現金比重是否合理
2. 風險監控師：以我寫的「最大可接受回檔 20%」評估目前曝險
3. 針對我列的三個問題逐一回答
4. 給我「下一步具體該做什麼」的 1–2 個建議
檔案沒有的資訊請標「資料未提供」，不要自行假設。
```

#### 👨‍🏫 教學重點：讓學員親眼看到 AI 說「資料未提供」

當 AI 回答「這部分你的檔案沒有提供」時，停下來強調：
- 這正是**純檔案模式**在保護你——它不會用幻想的數字騙你做決策
- 投資決策要基於**真實數據**，不是 AI 的想像
- 想補產業背景？按 🌐 打開上網，網路數字會跟你的檔案數字**分開標示**，不會混進去

### Step 3 — 把報告轉成 Word 健診書

報告出來後，到**一般對話**（不是團隊頁）貼上團隊報告全文，輸入：

```
幫我把這份個股健診分析做成一份排版乾淨的 Word 報告，
標題「個股健診報告」，分段清楚、含一張配置占比表。
```

→ 交給 `docx-gen`，產出可下載的 .docx 檔。

### 驗收標準

- [ ] 學員產出一份格式正確（表格 + 小標題）的持股 MD
- [ ] 用純檔案模式跑出健診報告，且報告中至少出現一次「資料未提供」或只引用檔案數字
- [ ] 成功把報告轉成 Word 檔下載

### 課後作業

把現金部位或某一檔的數字改掉，重新上傳跑一次，比較兩份報告的「風險評估」差在哪，體會「資料變、結論就變」。

## Lesson 3｜投資建議書 + 提案簡報 + 每週自動追蹤

> **實戰班・約 150 分鐘**
> 跑完整條商業線：財報濃縮成 MD → 客製「投委會團隊」分析 → 產出**投資建議書（Word）+ 提案簡報（PPT）** → 設**每週排程**持續追蹤。
> 這堂最有「機構味」，學員帶得走三樣具體成果。

### 學習目標

- 從零客製一支 5 人專業團隊（含「唱反調」角色）
- 把公開財報濃縮成分析用 MD
- 走完「分析 → Word 建議書 → PPT 簡報 → 每週追蹤排程」的完整產出鏈

### 時間分配（建議）

| 時間 | 內容 |
|------|------|
| 0–10 分 | 開場 + 合規免責 + 介紹投委會決策流程 |
| 10–35 分 | Step 1 客製 5 人投委會團隊 |
| 35–65 分 | Step 2 填財報 MD |
| 65–90 分 | Step 3 上傳分析、解讀投資長結論 |
| 90–125 分 | Step 4 產出 Word 建議書 + PPT 簡報 |
| 125–145 分 | Step 5 設每週追蹤排程 |
| 145–150 分 | 結業 Q&A |

### Step 1 — 客製「投資委員會」團隊

不用內建範本，自己組一支 5 人團隊（建團時逐一填角色職責 prompt）：

| 角色 | 綁定技能 | 職責 prompt |
|------|---------|------------|
| 基本面分析師 | research | 分析商業模式、營收結構、護城河、成長性 |
| 財務分析師 | data-analyst | 算毛利/營益率/ROE/負債比/自由現金流，判斷財務健康度 |
| 估值分析師 | data-analyst | 用本益比/PEG 做保守、中性、樂觀三情境估值 |
| 風險審查委員 | （留空） | 專挑反方理由與下行風險，扮演唱反調的人 |
| 投資長（拍板） | （留空） | 綜合各方給「買進/觀望/不買」與目標價、理由 |

> 👨‍🏫 教學重點：刻意放一個「**唱反調**」的風險審查委員。投資最怕只聽得進好消息——讓學員看到多角色辯論的價值。

### Step 2 — 做財報 MD

發放本教案最後的「[財報範本](#範本-2company-財報md)」，請學員從**公開財報**摘關鍵數字填入（一家就好）。

### Step 3 — 上傳分析

把 `company-XXXX.md` 拖進團隊提問框。
- 想嚴格只看財報 → 🌐 **關閉**（純檔案模式）
- 想讓它補最新股價 → 🌐 **開啟**（網路數字會跟財報分開標示）

```
附件是這家公司的財務資料。請投委會各角色根據檔案分析，最後由投資長給出：
①投資論點（為什麼值得/不值得買）②三情境目標價 ③最關鍵的三個風險
④明確結論：買進 / 觀望 / 不買，並說明條件。
注意：這是教學分析，不構成投資建議；檔案沒有的數字標「資料未提供」。
```

### Step 4 — 產出兩份交付檔案

把團隊報告全文拿到**一般對話**，分兩次產出：

**Word 投資建議書：**
```
把這份分析做成一頁式「投資建議書」Word 檔，
含投資論點、三情境目標價表、風險清單、最終結論。
```
→ `docx-gen`

**PPT 提案簡報：**
```
把這份分析做成 8 頁「投委會提案簡報」PPT，
要有估值三情境表格頁，最後一頁放明確結論與目標價。
```
→ `pptx-gen`

### Step 5 — 設每週追蹤排程

回團隊頁 → 排程 → 新增：

| 欄位 | 填什麼 |
|------|--------|
| 排程名稱 | `某某公司週追蹤` |
| 頻率 | **每週**，**週五 16:00** |
| 議題 | 見下方 |

```
根據先前對某某公司的分析，本週有什麼新消息或股價變化
會改變我們的投資結論？若觀點需要修正請指出。
```

> 👨‍🏫 教學重點：團隊**會記得上次的協作結論**，所以這題能做「**比較式追蹤**」——它會告訴你跟上週比有什麼變化。

### 驗收標準（結業作品）

- [ ] 客製出 5 人投委會團隊（含唱反調角色）
- [ ] 一份財報 MD + 一份投資長拍板的分析報告
- [ ] 一份 Word 投資建議書 + 一份 PPT 提案簡報
- [ ] 一個每週五自動追蹤的排程

### 結業挑戰

### 範本 2：company-財報.md

> 📋 學員填寫說明：選**一家**公司，從公開財報（公開資訊觀測站、年報、法說會）摘關鍵數字填入。只填重點，不要貼整份財報。填完存成 `company-XXXX.md` 上傳。

```markdown
# 公司投資分析資料：某某公司（代號）

## 近三年財務（單位：億元）

| 年度 | 營收 | 毛利率 | 營益率 | EPS | ROE |
|------|------|--------|--------|-----|-----|
| 2023 | 100 | 45% | 30% | 8.0 | 22% |
| 2024 | 130 | 48% | 33% | 11.0 | 25% |
| 2025 | 170 | 50% | 35% | 15.0 | 28% |

## 商業模式重點

- 主要產品：__
- 主要客戶 / 營收占比：__
- 護城河（技術、規模、轉換成本…）：__

## 目前股價資訊

- 現價：__
- 本益比：__
- 近一年區間：__ ~ __
```
